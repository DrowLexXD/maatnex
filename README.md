# MAATNEX

Sitio de presentación de **MAATNEX**, una plataforma de análisis forense de
documentos y audio con IA: lectura de múltiples formatos, detección de
entidades y palabras clave, clasificación de riesgo, expedientes con
importación de carpetas e informes en PDF.

La página pública está disponible en:

**https://drowlexxd.github.io/maatnex/**

## Estructura

- `index.html`: página de presentación (sitio estático, sin dependencias).

## Publicación

Este repositorio se publica con **GitHub Pages** desde la rama `main`
(carpeta raíz).
